Blare clock
-

This is my alarm clock with a display, buzzer and 4 buttons to customize it.

Features:
-

- It shows current time
- Custom alarms
- adjustable with switches.

Quick start:
-

1. Get all the needed parts
2. Solder the pcb - exclude the switches right now.
3. Place the heatset inserts into the case, and install the PCB
4. Next, solder the switches, and place the top layer under the switches.
5. DONE!
